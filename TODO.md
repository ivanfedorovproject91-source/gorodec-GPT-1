# Roadmap

- [x] Phase 1 — Foundation: app setup, PixiJS, empty world, camera, zoom, coordinate transforms, grid.
- [ ] Phase 2 — Object editor: create/select/move/resize/duplicate/delete, handles, undo/redo.
- [ ] Phase 3 — Procedural buildings: floors, adaptive facades, windows, doors, roofs, variations.
- [ ] Phase 4 — Infrastructure: editable road and railway paths, widths, bridges, intersections.
- [ ] Phase 5 — Advanced editor: multi-select, groups, copy/paste, layers, locking, library.
- [ ] Phase 6 — Visual polish: lighting, shadows, materials and depth.
- [ ] Phase 7 — Persistence: autosave, project management, JSON import/export and recovery.
- [ ] Phase 8 — Deployment: GitHub Pages/hosting preparation and Telegram Mini App compatibility.
